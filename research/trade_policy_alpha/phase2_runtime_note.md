# Phase 2 runtime note

The exact Canada Annex II valuation API uses point-in-time May 2026 Census merchandise imports and a disk-streaming ZIP parser. The Census monthly archive is streamed to `/tmp`; ZIP metadata is read from disk and `IMP_DETL.TXT` is decompressed and aggregated line-by-line so the full archive/detail file is never buffered in memory. The API remains a research-only audit endpoint and does not emit a tradable signal.

The production-audited Canada input for `US_CA_MOTOR_2026_07_20` is now frozen at **PolicyImpact = -0.4247525946% of GDP equivalent**. It is based on 439 legal-scope HTSUS8 provisions, of which 397 have positive Canada-to-U.S. Jan-May 2026 imports for consumption and 42 are valid zero-exposure lines. Covered Jan-May imports for consumption are USD 8.567448331bn; the explicit 12/5 run-rate gives USD 20.5618759944bn annualized, or CAD 28.217062427bn using May 2026 USD/CAD 1.3723, equal to 0.8495051893% of Q1 2026 nominal GDP SAAR. Applying the 50% tariff shock yields the frozen PolicyImpact above.

Phase 2A adds a policy-only seed replay for the 2026-07-20 Canada event using official Bank of Canada Valet series for USDCAD and the 2-year Government of Canada benchmark yield. It uses the last pre-event daily observation as the baseline and reports 1/5/10/20 post-event business observations. Event-day values are diagnostic only because the announcement timestamp is still date-precision. Carry, roll, transaction costs and statistical inference remain excluded, and the output is explicitly non-tradable until a multi-event transmission model is validated.
